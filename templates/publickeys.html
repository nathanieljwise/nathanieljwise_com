Public Key Cryptography

You can message me securely at nathanieljwise@protonmail.com. I have two public keys available - one a 4096 bit RSA key, and one for elliptic curve cryptography using curve P-384. To use them, generate some secure symmetric key, and then encrypt it to send to me. You can use my RSA key to encrypt the symmetric key directly, or you can use the ECC key as part of Elliptic Curve Diffie Hellman to derive a shared key.

You can use this example script to input either of my public keys and encrypt your message. The script will generate a secure 256 AES key, encrypt your content with AES-GCM, and output a single file containing the encrypted message and symmetric key. Send that to me above and I'll recover your message. The script is hybrid public-key encryption: ECDH-ES (P-384) or RSA-OAEP key wrapping with AES-256-GCM.
